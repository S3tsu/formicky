# FormičkyHub

Procvičování organické chemie pro studenty farmacie: názvosloví, reakce, mechanismy, syntézy, testy a Herna.

Web: https://s3tsu.github.io/formicky/

Celá aplikace je jeden soubor `index.html`. Pokrok se ukládá v prohlížeči (localStorage), přenést ho jde kódem zálohy na úvodní stránce.
