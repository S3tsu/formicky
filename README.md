# FormičkyHub

Procvičování organické a analytické chemie pro studenty farmacie: názvosloví, reakce, mechanismy, syntézy, důkazy iontů, spektra, testy a Herna.

Web: https://s3tsu.github.io/formicky/

Celá aplikace je jeden soubor `index.html`, jen 3D souřadnice molekul jsou zvlášť v `m3d.json` (načtou se až při otevření 3D modelu). Pokrok se ukládá v prohlížeči (localStorage), přenést ho jde kódem zálohy na úvodní stránce.
